# Printflow

To fully access our system, it is recommended to download the "printflow.zip" file.

# After downloading, make sure that you have the following applications:
* XAMPP
* VSCode

# To open the zip file, please follow the instructions below:
* Open File Explorer
* Look for the "xampp" folder
* Open it and find the "htdocs" folder
* Once inside the htdocs, create a new file named "printflow"
* Inside the printflow folder, drag the zip file and extract it.
* Once you have successfully extracted the files, you're almost done setting up the printflow system.

# IMPORTING THE DATABASE SQL
* Open XAMPP and open Apache and MySQL
* Go through your web browser and type "http://localhost/phpmyadmin/"
* Once you accessed the website, you'll see a small icon called databases at the left side of the page.
* Click "New" and name the database as "printflow_db".
* After creating the database, click printflow and look for the import icon at the top of the page.
* Choose a file and look for "printflow_db.sql" and open it.
* Scroll to the bottom and click "import"

After importing the database + PHP files, type in your search bar "localhost/printfow/login"
Congrats! You have successfully set up our system!
